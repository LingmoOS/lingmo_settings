# 设置 UI：macOS 参考设计（2026-11-08）

参考用户提供的“外观”“菜单栏”“桌面与程序坞”截图，使用 Lingmo SDK 原生控件和系统主题色，不引入平台专属的占位功能。

- 窗口保留左侧玻璃导航、右侧实色内容。浅色主题采用白色内容画布与浅灰分组卡片；深色主题使用主题背景层次。
- 导航栏宽 246px，项目行高 40px，文字约 13px；图标继续使用用户要求的系统强调色。搜索框高 34px。
- 页标题区域高 56px；分组卡片圆角 18px，常规行高 48px。分组标题与卡片文字保持同一左边缘。
- 可视化选项置于行右侧；窄窗口自动换到标签下方。预览是 SDK 绘制或项目已有 SVG，随缩放保持清晰。
- 外观：自动/浅色/深色预览、七种已有强调色、小组件自动/单色/全彩选项、文字与图标设置入口。
- 桌面与程序坞：屏幕位置预览、大小/放大/玻璃滑块、启动弹跳、隐藏策略、最小化区域、热区；桌面小组件显示与配置入口。
- 菜单栏：通透/着色背景预设、时钟/电池/网络/声音/通知中心入口、电池百分比开关，以及保留的模糊和透明度细调。
- 每个选项必须连接实际后端。尚无后端的系统功能不显示伪开关。菜单栏自动隐藏、跨设备功能、第三方菜单栏控件编排不在本轮范围内。
- “透明”“着色”预览对应现有菜单栏 opacity 设置，不能声称新增了整个系统的 Liquid Glass 材质模式。

验证使用临时 HOME、独立 D-Bus 会话和实际 SDK 无头渲染；截图不能替代真实桌面的玻璃合成验收。每轮构建测试后关闭 WSL。

## 本轮验证

- 实际编译 Settings 窗口与 appearance、dock、statusbar、desktopwidgets 四页及真实 Appearance 客户端。
- 24 项测试通过：翻译、搜索/导航历史、侧栏主题色、640px/1000px 选项布局、程序坞滑块与开关联动、菜单栏透明度/模糊、小组件外观设置保存。
- 四页生成中文明暗主题、100%/150% 共 16 张截图；检查了外观、菜单栏、程序坞页面及 150% 深色外观。
- 未执行整个系统的构建或真实桌面合成验收。本轮验证结束后已关闭 WSL。

## 预览插画修订

五张设置预览使用 SDK 原生矢量绘制。小组件自动模式展示同一天气卡片的彩色/单色分屏，单色模式完全去色，全彩模式保留主题色和黄色太阳；三者保留相同构图以便比较。菜单栏使用相同的几何壁纸与菜单图形，通透模式显示壁纸分区，着色模式用高不透明度中性底色明确区分。避免无意义装饰、高光堆叠和无法辨识的微缩文字。

预览图采用 Cover 等比放大填充，超出区域裁切。图片不自行绘制圆角，由选择控件统一按与边框同心的圆角剪裁，内缩 2px；选中状态只改变边框，不改变图片尺寸。仅新绘制的五张预览使用该模式，其他图标保持原有居中行为。
